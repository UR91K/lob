Main surface is either:
1. nodes view
    - 2d plane showing nodes with names
    - toggleable weak/ref/own edges
    - spring/gravity system to make graph self organise
2. list view
    - exactly like the "details" view in Windows Explorer.
    - adjustable columns + sorting
top bar: search bar
left sidebar: saved views
right sidebar: shows all metadata + data preview
    - data preview is an image viewer, audio player, video player, etc.
bottom bar: shows stats (total nodes, selected nodes, active operations, etc.)
